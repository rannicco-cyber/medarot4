Checks
  • Pixel width crossing the M4 VWF $89 threshold.
  • More than the selected number of rendered lines before a page break.
  • Unknown/unmeasurable glyphs or substitutions.
  • Malformed/unclosed control tags.
  • Control-code page/line transitions, including D3's context-dependent behaviour.
A width error means the text can reach beyond the normal M4 text area before an explicit break. It does not claim that every such case will visibly corrupt the ROM; it is a pre-build warning.
